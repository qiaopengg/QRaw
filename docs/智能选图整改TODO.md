## D. 五模式评分逻辑

- [x] `MODE-07` 风光中的远处或背景人物闭眼不得主导整张照片降分。

## 2026-08-04 UI 缺陷与检测几何修复记录

本轮只处理有代码级证据的具体缺陷，未对已放行的中部 UI 做整体视觉重设计。

- [x] `UI-09` 预览图鼠标滚轮缩放失效。根因：React 把 `wheel` 注册为 passive 监听器，JSX `onWheel` 内的 `preventDefault()` 被静默忽略，滚轮只滚动祖先容器而不缩放。改为原生 `addEventListener('wheel', ..., { passive: false })`。
- [x] `UI-10` 复核页右侧详情抽屉被遮罩拦截点击。根因：`review-decision-queue.css` 将遮罩提到 `z-index:31`、左抽屉提到 `32`，但漏同步右侧 `sc-inspector`（仍为旧文件的 `30`），遮罩盖在其上。已补齐为 `32`。
- [x] `UI-11` 打开抽屉时待确认队列被挤压、闪动、被推出可视区。根因不在 CSS 布局：`useDrawerFocus` / `Modal` 调用 `focus()` 未传 `preventScroll`，浏览器默认把新聚焦元素滚入视口，牵动祖先容器滚动；虚拟列表经 `ResizeObserver` 感知到尺寸抖动后重排。全部 `focus()` 已改为 `focus({ preventScroll: true })`。
- [x] `UI-12` 结果卡片说明文字实际未达 11px 无障碍下限。根因：`accessibility.css` 用 `:where()` 包裹选择器，specificity 低于 `smart-culling-gallery.css` 的局部规则，双方都带 `!important` 时局部规则获胜。改为具名选择器列表；同时说明文字收为单行并下调卡片预留高度，避免达标后反而更占位。
- [x] `UI-13` 窄宽度下文本/按钮重叠换行。根因：`base.css` 的 `.sc-page { min-width: 960px }` 同时是容器查询根，卡死宽度下限使既有 `@container` 窄屏断点永不触发。改为 `min-width: 0`。
- [x] `UI-14` 「设为 A / 设为 B」点击后无任何视觉反馈，交互体感等同不可用。底层状态流转本身正确，已补选中态（高亮 + `✓` + `aria-pressed`）并在相似组卡片上标出参与对比的项。
