# 智能选图：冻结技术底座与对抗式审查准则

- 版本：`qraw-smart-culling-foundation-1.0`
- 冻结日期：2026-10-28
- 授权依据：用户确认上一轮整体流程、分模式策略和人像打星标准，并要求将其作为第一性原理准则，重新质疑全部实现。
- 本文件冻结目标行为；[人像评分标准](./PORTRAIT_RATING_STANDARD.md)继续是人像分值的唯一规范，不另建评分入口。

## 1. 必须保持的产品不变量

| 编号 | 冻结规则 | 可证伪条件 |
| --- | --- | --- |
| F01 | 分析、建议、复核、确认写入分离。确认前不写智能选图星级/标签，弃选不删除原图。 | 扫描、推理或恢复流程改删照片，或未确认就落盘评分。宿主EXIF缓存不等于评分写入。 |
| F02 | 人像无基础星；主体明确不清晰为有效0且停评，清晰继续，清晰度无法确定无有效评分。 | 未知、无效或错主体证据进入有效0/正星；清晰本身被额外加星。 |
| F03 | 人像眼态通过+2、失败−2、未知0；表情严重失败/不推荐/自然/优秀/非常出色为−2/−1/0/+1/+2，未知0。 | 改分值、将未知伪装成自然、把表情训练标签当最终星级、让眼态/表情未知单独硬判0。 |
| F04 | 人像光学与构图分别有通过依据，两项均通过才合计+1；最终总分截断为0～5整数。 | 一个总审美分同时充当两项证据、任一未知仍加1、分别各加1、越界或非整数评分。 |
| F05 | 未评分与有效0分离；人工明确设置0～5成为有效人工结果并保护，不继续放待复核。 | 占位0被写入或弃选；颜色编辑确认占位分；人工决定被AI覆盖。 |
| F06 | 实际评分主体必须可对应；指定关键人物必须确认身份。 | 缺失、歧义、错位、重复或其他任务的人物证据被借给当前照片。 |
| F07 | 相似分组、推荐数量、关键人物表现排名不按名次直接升降星，组内第一不保证5星。特殊序列可要求复核。 | 为凑推荐比例改星；不可靠分组被当作独立身份或绝对质量证明。序列表情只能使用可靠的同人证据。 |
| F08 | 全部/有效1～5/有效0/未评分分区保持一致；未评分AI结果不能写入。 | 重复计数、缺失计数、未评分被确认、界面显示与实际写入对象不一致。 |
| F09 | 原图、已有人工决定与锁定优先；RAW/JPEG资产写入保持一致，失败和冲突明确保留。 | 陈旧分析覆盖已改变文件、半写成功却报全成功、恢复活跃事务、丢掉未重试失败。 |
| F10 | 非侵入feature接入；一个生效评分入口；依赖变更需授权；校准、工程等价与独立准确率分开。 | 修改上游业务、隐藏第二条评分路径、伪造数据或验收、未经证据解除发布限制。 |

## 2. 冻结的模式路由与权重

人像仅使用F02～F04离散规则。其他模式保留下表权重；清晰度硬门槛与证据缺失另行处理，不把缺失项权重转移给其他项。

| 模式 | 人物清晰度 | 眼态 | 表情 | 光学 | 构图 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 群像，指定关键人物 | 0% | 40% | 40% | 10% | 10% |
| 群像，未指定关键人物 | 0% | 0% | 0% | 90% | 10% |
| 环境人像 | 5% | 5% | 5% | 50% | 35% |
| 风景/自动无可靠人物 | 0% | 0% | 0% | 50% | 50% |
| 自动有可靠人物 | 50% | 15% | 15% | 10% | 10% |

自动模式检测到人物不等于切换到人像离散公式。权重是产品策略，不证明对应指标已经可靠；缺失证据引起跨星级区间时进入复核。

## 3. 必须重新质疑的实现假设

现有模型、颜色通道顺序、张量布局、检测分数公式、阈值、ROI映射、主体对应、分组启发式、置信度、线程时序、事务日志和文件身份检查都不是既定事实。既有测试只证明其断言，不能证明断言符合产品目标或真实照片准确率。

审查从F01～F10推导预期，先建立独立反例，再对照源码真实调用链。模型契约对照固定版本官方实现和权重哈希；程序行为使用故障注入、状态组合、边界值与并发屏障验证。禁止用实现自身输出作为真值，也不能复制实现条件生成必过测试。

缺陷须记录：违反的不变量、可达输入、修复前失败、最小修复、同一断言的修复后结果、未覆盖边界。没有证据的怀疑列为未决，不强行宣布有错或通过。失败测试、旧代码和历史报告不覆盖。

## 4. 本轮工作边界与变更纪律

清晰度研发继续暂停：不探针、不受控退化、不扫旧阈值、不重标、不索图。允许修复已有拒绝状态的丢失、错主体关联、无效数据传播等工程缺陷；不得趁机更换清晰度算法。用户暂时无更多数据，不阻止可独立验证的工程工作。

冻结的是规则，不是当前完成程度。当前光学/构图联合项+0、AI最高4星、release_ready=false均是未完成状态；以后只有真实证据和相应验收支持时才能更新，不能把它们永久固化为产品上限，也不能凭工程测试提前开启。

本版本不得静默改写。调整冻结规则须由用户明确决定，创建新规范版本并保留旧版本、理由和差异；普通实现修复沿用本版本并更新对应测试/证据。更换模型输入或分数语义必须审计依赖的阈值与校准兼容性，不得沿用旧准确率结论。

当前进度和未决问题统一见[交接文档](./PORTRAIT_SMART_CULLING_HANDOFF.md)；本规范不承诺审查已穷尽全部状态或已完成发布验收。
