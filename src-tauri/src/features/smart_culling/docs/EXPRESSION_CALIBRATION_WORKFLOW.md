# 智能选图：人像表情算法人工标注与联调方法

- 规范版本：1.1
- 状态：联调口径、第 001 批与第 002 批首轮人工标签已确认，五档模型及验收阈值待建立
- 适用范围：智能选图 `portrait`（人像）模式的表情判断
- 最终评分契约：[人像模式打星约束标准](./PORTRAIT_RATING_STANDARD.md)
- 协作操作手册：[人像表情联调傻瓜式协作手册](./EXPRESSION_CALIBRATION_COLLABORATION_PLAYBOOK.md)

## 一、目的

本文档固定人像表情算法的人工标注和联调方法，避免把“表情训练标签”误当成“照片最终星级”。

联调目标是利用人工标注照片，让算法学习：

1. 表情属于从严重失败到非常出色的哪一个有序层次。
2. 由代码根据证据完整性、模型状态和置信度决定是否能够输出该层次。
3. 将表情层次转换为正式评分增量，再交由最终评分规则综合计算。

本文档只定义表情算法的标注与联调流程，不修改人物主体清晰度、睁闭眼、光学质量、审美构图或最终星级规则。

## 二、人工标注契约

人工只使用 `1` 至 `5` 星标注照片中的人物表情：

| 人工标注 | 表情层次           | 正式表情评分增量 |
| -------: | ------------------ | ---------------: |
|   `1` 星 | 表情严重失败       |             `-2` |
|   `2` 星 | 表情不推荐         |             `-1` |
|   `3` 星 | 表情自然、基本可用 |             `+0` |
|   `4` 星 | 表情优秀           |             `+1` |
|   `5` 星 | 表情非常出色       |             `+2` |

“无法确定”只属于算法输出：

| 算法状态 | 人工标注 | 正式表情评分增量 | 用途                                 |
| -------- | -------- | ---------------: | ------------------------------------ |
| 无法确定 | 不存在   |             `+0` | 代码无法可靠判断时使用的安全弃权状态 |

必须遵守以下约束：

1. 人工星级是表情类别标签，不是智能选图最终星级。
2. 人工标注中不存在 `0` 星；人工必须在 `1` 至 `5` 星中给出表情质量答案。
3. “无法确定”由代码产生，不作为第六个人工类别，也不要求人工提供对应训练样本。
4. `1` 至 `5` 星构成从差到好的有序表情质量层次。
5. 算法“无法确定”和人工 `3` 星虽然正式评分增量都是 `+0`，但语义不同，推理和结果记录中不得合并。
6. 人工标注不得直接写入照片的最终星级；只能作为表情模型的监督数据和验证答案。

## 三、标注边界

每个样本只评价指定主人物的表情，不综合评价整张照片。

### 应当评价

- 面部表达是否明显失败、僵硬或不适合保留。
- 表情是否自然、基本可用。
- 表情是否具有更好的自然度、感染力和成片价值。

### 不应混入

- 人物主体是否清晰的最终门禁结论。
- 单纯的睁眼、闭眼或眨眼判定。
- 曝光、噪点、镜头光学质量。
- 画面构图和审美布局。
- 照片最终应获得几星。

人工能够观察照片时，必须根据表情质量标记为 `1` 至 `5` 星。即使代码因为模糊、遮挡、姿态、分辨率、面部缺失或模型故障而输出“无法确定”，人工标签仍然保持 `1` 至 `5` 星。文件损坏、没有目标人物或人工确实无法完成标注的样本属于无效数据，应从当前标注批次排除，不能标记为 `0` 星。

多人照片必须明确指定被标注的主人物。无法确定主人物，或无法保证标注对象一致的照片，不进入首轮单人像训练集。

### `1` 星与 `2` 星的操作边界

- `1` 星“表情严重失败”：表情已经严重失败，正常人像不应保留。
- `2` 星“表情不推荐”：尚未达到严重失败，但明显不推荐优先保留。

标注界面必须持续显示以上边界。只显示层次名称会使边界样本向 `1` 星漂移，不能作为稳定标注条件。

### `2` 星与 `3` 星的操作边界

- `2` 星“表情不推荐”：表情尚未严重失败，但明显不推荐优先保留。
- `3` 星“表情自然、基本可用”：表情达到正常人像的基本保留线。

标注界面必须持续显示以上边界，避免把“不推荐”和“基本可用”混为同一层次。

### `3` 星与 `4` 星的操作边界

- `3` 星“表情自然、基本可用”：表情达到正常人像的基本保留线。
- `4` 星“表情优秀”：表情质量明显优于基本可用，具有明确的优选价值。

标注界面必须持续显示以上边界，避免仅凭是否微笑区分 `3` 星和 `4` 星。

### `4` 星与 `5` 星的操作边界

- `4` 星“表情优秀”：表情质量明显优于基本可用，具有明确的优选价值。
- `5` 星“表情非常出色”：表情明显超越优秀，属于同批次中的顶尖表现。

标注界面必须持续显示以上边界。`5` 星是相对稀少的顶尖层次，不能把所有自然笑容直接判为 `5` 星。

## 四、数据记录格式

每个标注样本至少记录：

| 字段               | 必需 | 说明                                     |
| ------------------ | ---- | ---------------------------------------- |
| `sample_id`        | 是   | 样本唯一标识，不随文件名变化             |
| `image_ref`        | 是   | 图片路径或内部引用                       |
| `expression_label` | 是   | 人工表情标签，只允许整数 `1` 至 `5`      |
| `label_version`    | 是   | 本文档对应的标注口径版本                 |
| `subject_id`       | 建议 | 匿名人物标识，用于防止同一人物跨集合泄漏 |
| `capture_group_id` | 建议 | 同一连拍或相似场景组标识                 |
| `notes`            | 可选 | 边界样本、特殊表情或人工判断说明         |

`subject_id` 和 `capture_group_id` 应使用匿名标识，不记录人物真实身份。

## 五、联调流程

### 1. 建立冻结批次

将一批图片和人工标签固定为一个有版本号的数据批次。批次建立后，不静默覆盖原标签；纠正标签时生成新的数据版本并保留变更记录。

### 2. 检查标注有效性

检查图片可读取、标签位于 `1` 至 `5`、主人物明确，并识别重复文件、冲突标签和缺失字段。

### 3. 按人物和拍摄组拆分数据

训练集、校准集和盲测集必须按 `subject_id` 与 `capture_group_id` 隔离。同一人物或同一连拍不得同时出现在训练集和盲测集，避免算法记住人物或场景后产生虚高结果。

### 4. 分两阶段学习

人工标签和算法弃权状态必须分开处理：

1. 表情质量模型只学习人工 `1` 至 `5` 星的有序关系。
2. 代码根据输入证据可靠性、模型可用性和校准置信度决定是否安全输出质量层次。
3. 证据不足时输出“无法确定”，但不得把它训练成位于 `1` 星之下的第六个质量类别。

现有表情特征、非眼部面部特征和可靠性门禁应优先复用。不得把当前二分类概率机械切成五段冒充五档判断。

### 5. 在独立盲测集验证

每次算法或阈值调整后，至少记录：

- 五个表情质量层次的混淆矩阵。
- 各层次的精确率、召回率和样本量。
- 完全命中率，以及只相差一个相邻层次的比例。
- 算法“无法确定”的弃权率、原因分布，以及非弃权结果的准确率。
- 随置信度门槛变化的覆盖率与错误率，确认弃权机制确实降低错误风险。
- 跨人物、跨拍摄组和不同场景下的结果差异。

用于选择模型或调整阈值的数据不得继续宣称为独立盲测结果。

### 6. 人工复核错误样本

联调输出错误样本清单，重点复核：

- `1` 星与 `2` 星的边界。
- `3` 星与 `4` 星的边界。
- `4` 星与 `5` 星的边界。
- 算法输出“无法确定”时，对照人工 `1` 至 `5` 星答案检查弃权原因是否成立。
- 证据不足却被代码强行分入 `1` 至 `5` 星的样本。

人工确认是标签问题、模型问题还是阈值问题后，再进入下一轮；不得为了提高指标直接删除困难样本。

### 7. 冻结可追溯版本

每轮可用结果必须同时记录数据版本、标注口径版本、特征版本、模型版本、阈值版本和盲测结果。没有对应记录的模型不得替换正式算法。

## 六、接入最终评分

表情算法最终必须输出“无法确定”或本文定义的五个离散质量层次，再按照第二节的映射转换为 `-2` 至 `+2` 的表情评分增量。“无法确定”只记 `+0`，不得伪造成某个人工质量标签。

该增量必须继续与人物主体清晰度门禁、眼睛状态以及光学与审美构图结果共同按照 [人像模式打星约束标准](./PORTRAIT_RATING_STANDARD.md) 计算。人工训练标签本身永远不直接决定照片最终星级。

### 现有算法基线

当前 `qraw-expression-quality-hsemotion-fusion-calibration-0.5` 融合头只学习 `manual_rating >= 3`，输出一个二分类连续概率，不具备五档输出契约。

使用第 001 批 `v1.2` 人工表情标签回放 68 张已有底层证据后：

- 对“1–2 星 / 3–5 星”二分类目标命中 `58/68`（85.3%）。
- 连续分数与人工五档标签的 Spearman 相关系数为 `0.839`。
- 即使在同一批已知数据上事后选择最有利的四个阈值，五档完全命中也只有 `46/68`（67.6%），并且只形成 1 张 2 星预测。

因此不得将现有二分类概率机械切成五段。后续必须训练独立的有序五档模型头，并继续由单独的可靠性门禁产生“无法确定”。以上照片多数参与过旧模型选择或校准，指标只用于问题诊断，不是独立泛化成绩；另外 2 张因没有既有底层证据而未参与回放，这不等于算法已判定“无法确定”。
