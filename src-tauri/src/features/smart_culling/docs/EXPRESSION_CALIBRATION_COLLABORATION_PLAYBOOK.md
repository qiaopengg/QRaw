# 智能选图：人像表情联调傻瓜式协作手册

- 手册版本：1.3
- 状态：强制执行
- 适用范围：人像表情数据准备、人工标注、边界复核、盲测、算法基线、模型校准与新窗口续接
- 产品评分契约：[人像模式打星约束标准](./PORTRAIT_RATING_STANDARD.md)
- 算法联调规范：[人像表情算法人工标注与联调方法](./EXPRESSION_CALIBRATION_WORKFLOW.md)

## 一、手册目的

本手册固定 AI 与用户协作联调时的操作方式和回答方式。目标是让用户只完成必须由人判断的工作，其余目录管理、工具启动、数据检查、结果冻结、指标计算和进度恢复均由 AI 主动完成。

新窗口没有旧对话记忆时，AI 必须依靠本手册、配套规范和磁盘中的冻结结果恢复进度，不得要求用户重新解释已经记录的规则。

本手册只约束协作方式，不改变人工标签含义、正式表情评分增量或照片最终星级。

## 二、新窗口强制启动流程

收到“继续人像表情联调”、某批次“已完成”回执，或其他明显属于本流程的消息后，AI 必须先完成以下只读检查：

1. 完整阅读本手册。
2. 完整阅读 `PORTRAIT_RATING_STANDARD.md`。
3. 完整阅读 `EXPRESSION_CALIBRATION_WORKFLOW.md`。
4. 检查仓库状态，保护用户已有修改。
5. 检查 `/Users/qiaopeng/Desktop/测试` 下最新批次、标注结果、冻结版本和报告。
6. 以磁盘中的最新完整结果为准恢复阶段，不凭文件名或旧聊天摘要猜测。
7. 用一句话告诉用户“当前已经完成什么、现在只需要做什么”。

如果文档中的“当前恢复锚点”与磁盘结果冲突，以通过完整性校验的磁盘结果为准，并在本轮结束前更新恢复锚点。

## 三、固定协作原则

### 1. 用户只做必须由人完成的事

用户通常只负责：

- 把照片放进 AI 已创建并打开的指定文件夹。
- 在已打开的标注页面中观察照片并按数字键或按钮。
- 完成后回复 AI 给出的固定回执短语。
- 对确实需要摄影判断的边界问题作出选择。

除非工具客观不可用，不得要求用户：

- 打开终端或执行命令。
- 安装依赖、启动服务或填写端口。
- 手工创建复杂目录结构。
- 修改、合并或检查 JSON、CSV。
- 计算指标、查找重复照片或核对哈希。
- 手工冻结、复制、改名或归档结果。
- 重复说明已经写入文档的评分规则。

### 2. AI 主动完成机械工作

AI 负责：

- 创建并打开待放图目录。
- 只读盘点图片数量、格式、重复项和损坏项。
- 创建独立标注批次和结果目录。
- 启动本地标注工具并为用户打开页面。
- 检查是否全部标注，禁止把未完成批次当成完成批次。
- 计算分布、一致率、混淆情况、边界分歧和候选修正。
- 冻结 JSON、CSV、报告和版本哈希，保留旧版本不覆盖。
- 停止不再使用的本地服务。
- 更新联调报告、恢复锚点和下一步操作。
- 在充分验证前阻止实验参数进入 Release；用户明确要求先接入校准版时，必须保留校准标识、限制开关和可追溯记录。

### 3. 一次只交给用户一个清晰任务

AI 内部可以连续完成多项检查，但每次需要用户配合时，只给出一个动作闭环。例如：

1. 打开页面。
2. 明确本轮总张数。
3. 明确本轮允许使用的标签。
4. 用一句话重申本轮边界。
5. 给出唯一的完成回执。

不得同时要求用户准备下一批、复核上一批、修改文件和运行命令。

## 四、固定回答方式

### 1. 语言与节奏

- 始终使用简体中文，专业、直接、简洁。
- 先说结论或当前状态，再说用户下一步。
- 用户刚提交完成回执时，优先回复“收到，你先不用操作”，随后由 AI 检查数据。
- 不把内部命令、实现细节或长篇算法理论直接倾倒给用户。
- 需要解释技术结论时，先翻译成产品含义，再补充必要指标。
- 指标优先写成“命中数/总数”，百分比放在后面。
- 需要等待用户时，结尾只保留一个明确动作和一个固定回执。

### 2. 过程更新模板

开始核查时可使用：

```text
收到。你先不用操作。我会检查本轮是否全部保存、统计一致率，并按测试前确定的条件判断是否可以冻结。
```

发现阶段结果时可使用：

```text
结果已经明确：共 X 张，Y 张一致，Z 张需要边界复核。原图没有被修改。接下来我会先冻结本轮结果，再为你准备下一轮页面。
```

需要用户操作时可使用：

```text
现在你只做这一件事：在已经打开的页面中完成 X 张判断。完成后回复：`固定回执短语`
```

### 3. 最终回复必须自包含

每轮最终回复至少说明：

- 本轮结果是什么。
- 是否达到预先确定的条件。
- 哪些结果已冻结，是否保留旧版本。
- 原图和生产代码是否被修改。
- 用户现在唯一需要做的事。
- 完成后应回复的精确短语。

真实本地文件应使用可点击的绝对路径链接。

## 五、人工标签表达规则

用户界面和 AI 指导必须始终区分“人工表情标签”和“智能选图最终星级”。

| 人工标签 | 表情层次           | 正式表情评分增量 |
| -------: | ------------------ | ---------------: |
|   `1` 星 | 表情严重失败       |             `-2` |
|   `2` 星 | 表情不推荐         |             `-1` |
|   `3` 星 | 表情自然、基本可用 |             `+0` |
|   `4` 星 | 表情优秀           |             `+1` |
|   `5` 星 | 表情非常出色       |             `+2` |

必须反复遵守：

1. 人工只标 `1` 至 `5` 星，不存在人工 `0` 星。
2. “无法确定”只由算法的可靠性和置信度门禁产生。
3. 人工标签不是照片最终星级，不能直接写入最终评分。
4. 人工只评价主人物表情，不混入清晰度、睁闭眼、曝光或构图。
5. 边界测试时只允许用户使用本轮指定的两个相邻标签。

### 人工复核一致性验收

人工判断允许正常的相邻档位波动，不追求逐张标签像公式一样永远完全相同。覆盖 `1` 至 `5` 星的代表性复核满足以下三项即通过：

1. 完全一致率达到 `90%` 至 `100%`。
2. 其余分歧全部只相差一个相邻层次。
3. 相差两档及以上的跨级分歧为 `0`。

分层指标只用于诊断系统性偏移，不设置每档少量样本硬门槛。满足总体条件后必须停止复核，不因少量 `4→5`、`2→1` 等变化追加无尽的纠错、定向复核或混合测试，也不自动覆盖冻结标签。人工 `0` 星仍不存在。

## 六、每轮标准操作闭环

### 阶段 A：准备

1. AI 创建独立批次目录和结果目录。
2. AI 检查图片可读性、数量、重复内容和扩展名。
3. 原图保持只读；标注结果只能写入独立结果目录。
4. AI 在用户操作前写明本轮目的、样本数和通过条件。

### 阶段 B：用户标注

1. AI 启动仅监听 `127.0.0.1` 的本地标注工具。
2. AI 主动打开页面；若没有自动出现，再提供可点击地址。
3. AI 只告诉用户本轮应关注的表情边界。
4. 页面自动另存、自动续接，不要求用户手工保存。
5. AI 给出唯一完成回执，例如：`2星3星混合盲测完成`。

### 阶段 C：结果核查

收到完成回执后，AI 必须：

1. 核对 `completed == total`。
2. 核对 JSON 与 CSV 记录数一致。
3. 按内容哈希映射回原始照片，不依赖盲测文件名。
4. 统计总体完全一致率、相邻误差率、跨级误差数、各层次诊断指标和全部分歧样本。
5. 对照测试前条件作出决定，不得看完结果后降低标准。
6. 未完成时只说明剩余数量并重新打开页面，不提前分析。

### 阶段 D：冻结与推进

1. 通过后创建新冻结版本，绝不覆盖旧版本。
2. 复制完成后比较 SHA-256，确认冻结文件与原结果一致。
3. 标签纠正必须记录原标签、新标签和原因。
4. 少量相邻分歧作为正常感官波动记录，不自动覆盖历史标签；只有系统性问题才进入专项排查。
5. 停止旧标注服务，再启动下一批，避免端口和结果目录混用。
6. 更新报告、配套规范和本手册的恢复锚点。

## 七、固定决策逻辑

### 1. 达到预设条件

- 完全一致率达到 `90%` 至 `100%`、其余均为相邻误差且没有跨级误差时，冻结本轮结论。
- 保持既有冻结标签，不为追求逐张完全相同自动修正相邻分歧。
- 停止继续复核，转入下一阶段。
- 明确告诉用户“已通过”和下一步。

### 2. 接近条件但存在少量分歧

- 如果总体完全一致率仍达到 `90%`，且分歧全部相邻，则已经属于通过，不进入本分支。
- 只有总体完全一致率低于 `90%`、出现跨级误差或存在多轮同方向系统性漂移时，才做专项复核。
- 专项复核仍不直接覆盖冻结标签，也不得通过反复测试把感官波动强行抹平。

### 3. 未达到条件

- 不冻结为可用边界。
- 不通过删除困难样本美化指标。
- 区分标签问题、模型问题、阈值问题和证据缺失。
- 给用户一个最小、明确的下一步，不连续叠加试验。

### 4. 数据不足

- 不把小样本拟合结果伪装成已验收的 Release 模型；用户明确授权校准接入时，只能进入受限校准路径。
- 不把同批训练或校准成绩称为独立盲测准确率。
- 优先补充缺少的层次、人物和拍摄组，再训练候选模型。

## 八、数据安全与版本纪律

1. 不修改、覆盖或删除用户原始照片。
2. 盲测目录优先使用只读符号链接或独立副本，盲测名称不得泄露历史标签。
3. 每个结果版本必须保留 JSON、CSV、版本号和必要报告。
4. 冻结版本不得静默覆盖；发现目标版本已存在时停止并核查。
5. 必须验证样本唯一标识、标签范围、JSON/CSV 一致性和原图内容哈希。
6. 人物与拍摄组使用匿名标识，不记录真实身份。
7. 用于模型选择或阈值调整的数据以后只能称为已知校准数据。
8. 生产算法修改必须继续遵守 `docs/feature-integration-guidelines.md`，不得侵入上游 RapidRAW 代码。
