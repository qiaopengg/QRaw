# 智能选图：人像模式打星约束标准

- 规范版本：1.0
- 状态：离散评分已接入正式调用链；五档表情头处于 macOS Debug 校准状态
- 适用范围：仅适用于智能选图的 `portrait`（人像）模式
- 不适用范围：群像、环境人像、自动、风景模式
- 配套联调规范：[人像表情算法人工标注与联调方法](./EXPRESSION_CALIBRATION_WORKFLOW.md)
- 配套协作手册：[人像表情联调傻瓜式协作手册](./EXPRESSION_CALIBRATION_COLLABORATION_PLAYBOOK.md)
- 清晰度、光学与构图方案：[调研与接入结论](./PORTRAIT_QUALITY_RESEARCH.md)

## 一、最终星级约束

1. 最终星级只能是 `0`、`1`、`2`、`3`、`4`、`5` 中的整数。
2. 最终星级不得低于 `0` 星，也不得高于 `5` 星。
3. 人像模式没有默认基础星级；人物主体清晰本身不加星。
4. AI 已完成判定且最终为 `0` 星的照片进入“AI 弃选区”，用户可再次审查和人工恢复；清晰度无法确定时属于未完成评分，进入“待人工复核”。

结果筛选顺序固定为“全部 / 智能选图 / AI 弃选区 / 待人工复核”：有效 `1–5` 星进入智能选图，有效 `0` 星进入 AI 弃选区，无有效评分进入待人工复核。AI 尚待复核时，数字星级仅为占位；人工明确设置的 `0–5` 星属于有效评分，按分值进入对应分区，保持人工来源和锁定，不再计入待人工复核。三个结果区互斥，数量相加等于全部；弃选仅为分类，不删除原图。

## 二、判定顺序与计分规则

### 1. 人物主体清晰度门禁

人物主体清晰度是先于其他评分项执行的硬门禁：

| 判定结果       | 处理方式                                          |
| -------------- | ------------------------------------------------- |
| 人物主体不清晰 | 最终直接判定为 `0` 星，不再使用其他评分项改变结果 |
| 人物主体清晰   | 不加星，继续执行眼睛、表情、光学与审美构图判定    |
| 无法确定清晰度 | 不产生有效最终星级，进入待人工复核，不视为弃选 |

### 2. 人物眼睛状态

| 判定结果         | 星级增量 |
| ---------------- | -------: |
| 无法确定         |     `+0` |
| 通过睁闭眼验证   |     `+2` |
| 不通过睁闭眼验证 |     `-2` |

眼睛状态无法确定时只记 `+0`，不得单独强制整张照片变为 `0` 星。

### 3. 人物表情状态

| 判定结果           | 星级增量 |
| ------------------ | -------: |
| 无法确定           |     `+0` |
| 表情严重失败       |     `-2` |
| 表情不推荐         |     `-1` |
| 表情自然、基本可用 |     `+0` |
| 表情优秀           |     `+1` |
| 表情非常出色       |     `+2` |

表情状态无法确定时只记 `+0`，不得单独强制整张照片变为 `0` 星。

### 4. 照片光学与审美构图

光学参数和审美构图共同组成一个联合评分项：

| 判定结果                     | 星级增量 |
| ---------------------------- | -------: |
| 光学参数和审美构图均通过验证 |     `+1` |
| 任一项未通过或无法通过验证   |     `+0` |

此处最高总计只加 `1` 星，不是光学和构图分别各加 `1` 星。

## 三、最终星级计算

人物主体清晰时：

```text
原始星级 = 眼睛状态增量 + 表情状态增量 + 光学与审美构图增量
最终星级 = clamp(原始星级, 0, 5)
```

人物主体不清晰时：

```text
最终星级 = 0
```

负分只参与原始星级计算，最终结果不能出现负星。人物主体清晰的照片仍可能因为各评分项相加后不大于 `0` 而最终得到 `0` 星，并进入弃选区。

## 四、边界示例

| 主体清晰度 | 眼睛 | 表情 | 光学与构图 |                   最终星级 |
| ---------- | ---: | ---: | ---------: | -------------------------: |
| 不清晰     | `+2` | `+2` |       `+1` |        `0`（清晰度硬门禁） |
| 清晰       | `+2` | `+2` |       `+1` |                        `5` |
| 清晰       | `+2` | `+0` |       `+1` |                        `3` |
| 清晰       | `-2` | `+2` |       `+1` |                        `1` |
| 清晰       | `+0` | `+0` |       `+0` |          `0`（进入弃选区） |
| 清晰       | `-2` | `-2` |       `+0` | `0`（原始 `-4`，下限截断） |

## 五、实施约束

1. 本文档是人像模式打星的唯一产品口径；实现不得继续使用与本文冲突的加权百分比或星级硬编码。
2. 模型输出必须先映射为本文规定的离散状态，再计算星级。
3. 调整任何状态含义、分值或上下限时，必须同步更新策略版本和回归测试。
4. 本标准只约束打星，不定义人物主体识别、清晰度阈值、眼态阈值、表情模型阈值或相似照片分组方法；这些规则后续分别确认。

## 六、当前实现状态

截至 2026-09-10，策略版本 `qraw-portrait-rating-discrete-1.0` 已接入人像模式正式评分调用链：

1. `portrait_rating.rs` 负责本文规定的纯离散计算，`portrait_rating_adapter.rs` 只负责把现有证据映射为离散状态。
2. 人物主体明确不清晰时直接得到 `0` 星；清晰度证据无法确定时仍进入人工审核，不伪造成“不清晰”。
3. 眼睛验证失败按 `-2` 参与计算，不再使用旧的 `1` 星硬限制；眼睛无法确定或刻意闭眼候选按 `+0` 处理。
4. 表情直接输出五个质量层次并映射为 `-2` 至 `+2`；表情无法确定按 `+0` 处理，不再阻断整张照片评分。
5. 已确认的 AI `0` 星结果可以进入弃选区并由用户恢复，不再被写入规则误判为无效结果。
6. 当前尚无经过联合验证的“光学参数和审美构图均通过”判定，因此该联合项暂记 `+0`。在补齐该判定前，人像自动评分的实际上限为 `4` 星，不能虚构 `+1` 证据。
7. 人像旧固定权重、连续分数换星阈值及对应失效理由分支已移除；人像没有加权策略配置，误入通用换星路径会显式失败。其他拍摄模式的既有策略保持独立。
8. 新增 eDifFIQA(T) 人脸质量、局部双尺度细节、曝光/色彩与三分/居中/黄金交点位置观测，已接入人像结果和复核面板。当前仅收集证据，**未替换生效的清晰度阈值，也不触发弃选或联合 +1 星**；输入无效、模型缺失和推理失败均保留具体原因及空分值。新模型实测与后续校准边界见[接入记录](./PORTRAIT_QUALITY_RESEARCH.md)。
9. 清晰度专用原图输入已接通，复用 EXIF 方向和无重采样的旋转/翻转/裁剪，支持宿主无编辑 `null` 快照并隔离解码器的 EXIF 缓存副作用。0.1 抗噪失败，0.2/0.4 因原图特征重叠拒绝拟合，0.3 抗扰未知超限，均未替换正式门禁。已执行本机 GPU、桌面评分/保护流程、ARW/RAF/NEF 解码像素对照和单张真实 NEF 人像未评分流程；这些不证明算法准确。用户“测试/全部表情”已盘点，无法满足独立留出且暂时没有其他材料；RAW 人像准确率、真实摄影独立留出及光学/构图通过线仍未验收。详见[最新记录第 13 节](./PORTRAIT_QUALITY_RESEARCH.md#13-噪声机制04-失败与桌面安全闭环2026-09-10)。
10. 未知在所有智能选图评分控件显示“未评分”，不显示为有效 0 星；只改颜色不能确认占位评分。明确人工 0～5 星后按有效评分进入对应分区，保留人工来源和锁定，不继续计为待复核。确认前不写智能选图星级或标签；宿主图库可能另行缓存 EXIF 元数据。
11. 2026-09-11 按用户要求暂停清晰度研发，推进其他功能。后端已向复核界面传递真实离散评分明细及主体状态；左右眼和五档表情可独立查看，待复核/清晰度停评时不显示单项合计为有效评分。人工改分后原AI观测保留，但不覆盖人工星级。本阶段工程回归及构建通过；用户解锁后，3张隔离副本已完成真实分析、明细、人工0/5星、确认写入和再次分析的人工保护验证，原图未改。旧预检等待及锁屏证据保留，根因尚未确定；本轮不是识别准确率验收，光学/构图联合+1仍未实现。详见[当前交接第5.1节](./PORTRAIT_SMART_CULLING_HANDOFF.md#51-最新方向暂停清晰度推进其他功能)。

五档表情头 `qraw-expression-quality-ordinal-calibration-0.3` 仅在既有 macOS Debug 校准路径启用；Release、非 macOS 泛化、真实相机盲测和模型权重许可仍未通过，不能据此宣称正式发布可用。
