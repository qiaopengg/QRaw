# 人脸清晰度联调：第 001 批操作与预设条件

- 版本：`qraw-clarity-pilot-1`，2026-09-09，标注前固定。
- 评分规则仍以 [PORTRAIT_RATING_STANDARD.md](./PORTRAIT_RATING_STANDARD.md) 为唯一依据。
- 协作方式沿用[傻瓜式协作手册](./EXPRESSION_CALIBRATION_COLLABORATION_PLAYBOOK.md)。

## 本轮只做什么

从既有测试素材准备 24 张独立内容，只判断画面中绿色框指定的人脸清晰度。原图与原像素人脸细节并排显示；默认 100% 是一个源像素对应一个屏幕物理像素，200% 仅供放大观察，不生成新图片。不显示模型分数、历史表情标签或来源文件名。

| 按钮 | 人工含义 | 数据用途 |
| --- | --- | --- |
| 1 · 清晰 | 面部细节可辨，达到用户正常保留的清晰度 | 清晰锚点候选 |
| 2 · 明显模糊 | 确实失焦或运动模糊，脸部细节明显丢失 | 模糊锚点候选 |
| 3 · 暂不判断 | 边界拿不准、遮挡、脸太小或指定脸框不对 | 保留并单独诊断，不强行当作模糊或清晰 |

这三个数字是按钮编号，**不是人工表情星级，也不是照片最终星级**。第 3 项不是算法“无法确定”的训练类别；它记录本次人工不提供二分类真值。表情人工标签仍只允许 1–5 星且不存在人工 0 星，历史表情规范不变。

用户只需在已打开页面选择按钮或按 1/2/3；自动另存、自动续接。完成回执：`清晰度第001批标注完成`。

## 数据边界（标注前冻结）

1. 从已有 `优化调试/source` 的 10 个文件名前缀组、`表情真实照片优化调试/calibration-normalized/source` 的 13 个前缀组及 `智能筛选` 目录各取一张。每组按内容 SHA-256 选择未重复的最小哈希，不看历史星级或新质量分数。
2. 前缀仅是来源组提示，**未经确认的人物和拍摄组不自动填充**。素材来源统一暂记未核验，不能因为文件夹叫“真实照片”就宣称全部为真实相机原片。
3. 全部 24 张均为已知素材的清晰度试标/校准集；本轮没有独立盲测集，不按随机图片拆分伪造人物隔离。之后任何调参使用过的照片及同人同组都不得再称为独立盲测。
4. 保留全部候选源文件清单、源文件哈希、只读匿名链接、指定脸框、模型/预处理版本及原始观测。指定框只用于本次标注，不修改应用主人物选择规则。
5. 人工只能看到原图，无人工加模糊、降噪、锐化或美颜变体。采样不保证已经覆盖所有困难场景；小脸、侧脸、暗光、噪声、美颜、背景干扰的实际覆盖必须在分析时逐项列出，缺失不能记为通过。
6. 本轮使用 `decodedRgb8`；不得未经验证直接将其门槛用于 `renderedRgb8`、RAW 或编辑后预览。像素方向必须一致，发现 EXIF 旋转时停止准备，不静默排除。

## 本轮完成条件与停止规则

- `completed == total == 24`；清晰度 JSON 与 CSV 同一清单、同一指定人脸、同一标签，且只有 1/2/3。
- 源文件、匿名链接、观测、清单和本协议哈希一致；没有修改照片、旧标签或生产评分参数。
- 满足以上条件就冻结首轮结果。**不套用表情 90% 一致率做重复人工复核，不以“标注完成”冒充算法验收**。
- 用户完成后，AI 直接做旧门禁与新观测的误判诊断、清晰/模糊可分性和候选规则分析。边界样本完整保留、单独报数，不反复追求人工逐张完全一致。
- 若不足以形成候选，明确缺的是哪一种证据、缺多少；不要再次笼统要求一轮表情标注。模型故障和不能定位脸不当成“明显模糊”。

## 候选算法验收口径（先固定，尚未验收）

清晰度最终仍只有清晰、不清晰、无法确定三态。候选必须报告原始人数/照片数和以下三个比例：

- 清晰误弃率 = 人工清晰但算法不清晰 / 全部人工清晰。
- 模糊误放率 = 人工明显模糊但算法清晰 / 全部人工明显模糊。
- 弃权率 = 算法无法确定 / 全部具备明确人工清晰或模糊答案的样本；另外单独列出人工暂不判断数量及其算法输出。

进入受限候选对照的预设底线：清晰误弃为 0 张、模糊误放不超过 10%、算法弃权不超过 20%，且明确结论的正确数 / 全部有明确人工答案的样本数至少 90%。分母为 0 时为不可评估，不能记作通过。这只是校准候选筛选底线，不是已证明的错误率上界，也不授权自动写入生产阈值。

本批不足以证明泛化。替换生效门禁前必须先冻结候选版本与阈值，再在未用于调参、人物/拍摄组隔离的留出数据上按同一口径评估；每个二分类真值至少 20 张，各困难场景覆盖单独列明，不足则只报告诊断。揭示答案后不降低条件，不通过大量“无法确定”包装准确率。正式 Release 的规模及可信区间验收仍另行确认。
